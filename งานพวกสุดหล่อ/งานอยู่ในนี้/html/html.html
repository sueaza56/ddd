HTML(HyperText Markup Language)

เป็นภาษาที่ใช้สำหรับสร้างและกำหนด โครงสร้างของหน้าเว็บไซต์ โดยใช้แท็ก(Tag) เพื่อบอกเบราว์เซอร์ว่าเนื้อหาแต่ละส่วนมีหน้าที่อะไร เช่น หัวข้อ ข้อความ รูปภาพ ลิงก์ และตาราง HTML เปรียบเสมือนโครงสร้างพื้นฐานของเว็บไซต์

TAG

Tag (แท็ก) คือคำสั่งใน HTML ที่ใช้กำหนดว่า เนื้อหาส่วนนั้นมีหน้าที่อะไร เพื่อให้เว็บเบราว์เซอร์เข้าใจและแสดงผลได้ถูกต้อง

Tag ที่นิยมใช้ใน HTML

HTML มี Tag ให้เลือกใช้หลายประเภท แต่มีบาง Tag ที่พบได้บ่อยในการสร้างเว็บไซต์ เช่นในรูปตัวอย่างของเรา
