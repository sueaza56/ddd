CSS(Cascading Style Sheets)

เป็นภาษาที่ใช้สำหรับตกแต่งหน้าเว็บไซต์ให้สวยงาม และจัดรูปแบบโดยใช้ คลาส(class) หรือ ไอดี(id) เพื่อตกแต่ง จัดรูปแบบต่างๆ เช่น ใส่สีพื้นหลัง ข้อความ จัดให้อยู่กึ่งกลาง เรียงแถวแบบไหนCSS เปรียบเสมือน หน้าตาของเว็บไซต์

Class และ Id คืออะไร

ใน CSS จะมีการเรียกชื่อtag ต่างๆด้วย class id โดย คลาส(class) จะมีElementหลายตัวได้ จะมีสัญลักษณ์นำหน้าด้วย . ตามด้วยชื่อclassที่ตั้ง เช่น class="suea" ก็คือ .suea ไอดี(id) จะมีElement ได้แค่ตัวเดียวต่อ 1 id จะมีสัญลักษณ์นำหน้าด้วย # ตามด้วยชื่อ id ที่ตั้ง เช่น id="suea" ก็คือ #suea

วิธีใช้งาน CSS

มีวิธีอยู่ 3 วิธี

1.แก้ไขใน tag เลย(มือใหม่)

2.แก้ไขใน ไฟล์html เลย(เริ่มเข้าใจ)

3.สร้างไฟล์แยกแล้วเชื่อมต่อ(คนเก่งเข้าใจมีระเบียบ)

1.แก้ไขใน tag เลย

การแก้ไขใน tag เลยเหมาะสำหรับเว็บไซต์ขนาดเล็ก เพราะมีการจัดการที่น้อยไม่ค่อยสับสน แต่หากเว็บไซต์มีขนาดใหญ่ไม่ควรใช้แก้ไขทุกอย่าง เพราะอาจเกิดการสับสน งงว่าอันนี้คืออันไหนแต่ข้อดี คือใช้ง่าย เหมาะสำหรับการเริ่มเขียนการใช้งาน ใส่style ลงในtag เพื่อบอกว่าในนี้จะเป็นการตกแต่ง จัดรูปแบบ

2.แก้ไขใน ไฟล์html เลย

การแก้ไขใน ไฟล์html เหมาะสำหรับเว็บไซต์ขนาดเล็กถึงกลาง เพราะมีการจัดการที่มากขึ้น ซับซ้อนขึ้น มีระเบียบและมีการใช้ class id เข้ามา แต่มีข้อเสียคือไม่สามารถจัดการ class หรือ id จากไฟล์ html อื่นได้ทำให้บางทีต้องเขียนแบบนี้ในทุกไฟล์ทำให้ลำบากนิดนึงสำหรับบางคน การใช้งาน สร้าง tag style ก่อน tag body เพื่อบอกว่าในtagนี้จะเป็นcss และมีการจัดรูปแบบดังรูปตัวอย่าง

3.สร้างไฟล์แยกแล้วเชื่อมต่อ

การสร้างไฟล์แยกแล้ว เชื่อมต่อ(link) ทำได้โดยสร้างไฟล์ css นามสกุลไฟล์ .css ให้ที่อยู่ของไฟล์ css อยู่ในfolder เดียวกับไฟล์html ที่จะเชื่อมและเชื่อมโดยใช้ tag link ใส่ไว้ในtag head โดยให้ rel="stylesheet" นี่คือบอกว่าที่จะลิ้งมันทำหน้าที่อะไรอันนี้คือในท่นี้คือการตกแต่งเว็บไซต์ แล้วกำหนด href="ชื่อไฟล์.css" ตามรูปตัวอย่าง
