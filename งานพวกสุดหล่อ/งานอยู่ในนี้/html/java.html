JavaScript (JS)

เป็นภาษาที่ใช้สำหรับสร้างการทำงานและการโต้ตอบของเว็บไซต์กับผู้ใช้งาน โดยใช้ฟังก์ชัน (function) และเหตุการณ์ (Event) เพื่อกำหนดว่าเมื่อผู้ใช้ทำบางอย่างแล้ว เว็บไซต์จะทำงานอย่างไร เช่น การกดปุ่มแล้วมีข้อความแจ้งเตือน การเปลี่ยนข้อความ หรือการตอบสนองต่อการกระทำต่าง ๆ ของผู้ใช้

วิธีเชื่อม JavaScript

วิธีเชื่อมต่อ JavaScript มีอยู่ 2 วิธี ได้แก่

1. เขียน JavaScript ในไฟล์ HTML โดยใช้ tag <script> แล้วเขียนโค้ด JavaScript ภายใน tag นั้น

2. เชื่อมกับไฟล์ JavaScript ภายนอก โดยสร้างไฟล์ .js แล้วใช้ tag <script> พร้อมใส่ src เพื่อเชื่อมไปยังไฟล์ JavaScript

ฟังก์ชัน (function) คืออะไร?

ฟังก์ชัน คือชุดคำสั่งที่ใช้กำหนดการทำงานของโปรแกรม และสามารถเรียกใช้ซ้ำได้ ฟังก์ชันสามารถรับข้อมูลเข้ามาประมวลผล และสามารถส่งค่ากลับออกมาได้ ตัวอย่างรูปแบบฟังก์ชัน เช่น function hello() { }

addEventListener คืออะไร?

คือคำสั่งที่ใช้สำหรับตรวจจับเหตุการณ์ (Event) ที่เกิดขึ้นกับ Element เช่น การคลิก การกดคีย์บนคีย์บอร์ด การเลื่อนเมาส์ และเหตุการณ์อื่น ๆ

ตัวแปร (Variable)

ใน JavaScript มีคำสั่งที่ใช้ประกาศตัวแปรหลัก ๆ 3 แบบ ได้แก่ var, let และ const โดย var และ let สามารถกำหนดค่าใหม่ให้ตัวแปรได้ ส่วน const ใช้สำหรับประกาศตัวแปรที่ไม่สามารถกำหนดค่าใหม่ให้ตัวแปรเดิมได้ ตัวแปรสามารถใช้เก็บข้อมูล เช่น ข้อความ ตัวเลข หรือข้อมูลอื่น ๆ เพื่อนำไปใช้งานในโปรแกรม

ตัวอย่างโค้ด
